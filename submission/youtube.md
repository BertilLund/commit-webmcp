## Title

Commit — Git for Agent Actions on the Web | WebMCP Challenge

## Description

Commit is a working WebMCP-native collaboration pattern for state-changing web apps.

An agent stages a coherent set of commerce operations in safe shadow state. A human reviews or edits the shared plan, deterministic policies validate it, and only an approved unchanged revision can commit atomically. Every commit creates an audit record and can be safely staged for rollback.

In this demo, a WebMCP agent prepares a weekend clearance campaign, receives a below-margin policy block, reacts to a human price edit, and commits only after explicit human approval.

Live app: https://commit-webmcp.pages.dev
